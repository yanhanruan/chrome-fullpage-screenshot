Test 12: Responsive Layout

📱 Responsive Layout Test

Test the screenshot effect under different window sizes - try to resize the browser window before taking a screenshot

💡 Test Description

This page uses a responsive design that automatically adjusts its layout based on the viewport width. You can try resizing the browser window to different widths (e.g., 375px, 768px, 1024px, 1920px), then use the screenshot plugin to take a screenshot and check if the layout is correct for each size.

🎯 Test Goal

Verify that the plugin can correctly capture responsive layouts instead of being fixed at a certain size.

📐 Adaptive

The page will automatically adjust the number of columns, font size, and spacing according to the viewport width.

🔍 Checkpoints

The screenshot should reflect the actual layout state under the current window size.

✅ Expected Behavior

A correct screenshot plugin should:

  • ✓ Capture the layout at the current viewport width
  • ✓ Maintain the effect of responsive breakpoints
  • ✓ Correctly display media query styles
  • ✓ Not force a switch to a fixed width
  • ✓ Screenshot size matches the actual page size

1️⃣ Step 1

Adjust the browser window to the width you want to test (e.g., 768px)

2️⃣ Step 2

Observe if the page layout is correctly displayed according to that width

3️⃣ Step 3

Take a screenshot using the screenshot plugin

4️⃣ Step 4

Check if the screenshot correctly reflects the current responsive layout

💡 Tip

The actual size of the current page is displayed in the bottom left corner. After the screenshot is completed, compare the size of the screenshot with the size displayed here; they should be consistent (or close, considering scrollbars, etc.).
