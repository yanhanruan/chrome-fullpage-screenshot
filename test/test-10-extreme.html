⚠️ Test Description

This is an oversized page of 4000×40000 pixels, with a total pixel count of 160,000,000 (160MP), equivalent to approximately 640MB of uncompressed image data.

The purpose of this test is not to successfully capture the full page, but to verify the plugin's behavior when faced with extreme situations:

  • ✅ Whether the protection mechanism (size limit) is triggered
  • ✅ Whether clear warning information is displayed to the user
  • ✅ Whether a degradation strategy (cropping or scaling) is adopted
  • ✅ Whether the browser stays stable (no crash)
  • ✅ Whether the user experience is friendly (with feedback, no freezing)

🔬 Technical Details

Why this page is so extreme:

  • Pixel Count: 160MP is 40 times that of an ordinary photo
  • Memory: Approx 640MB memory needed in RGBA format
  • Rendering: The browser needs to render all these pixels
  • Encoding: PNG compression also takes a lot of time
  • Transmission: Downloading may take dozens of seconds

🚀 Performance Considerations

Even if hardware allows, capturing such a large page requires considering:

  • User Time: May take 20-60 seconds
  • CPU Usage: 100% usage for dozens of seconds
  • Memory Peak: May exceed 2GB
  • File Size: PNG may be 50-200MB
  • Utility: Do you really need such a large image?

🤔 Reality Scenarios

In the real world, there are almost no pages like this:

  • 40000px height is equivalent to 25 times an ordinary screen
  • 4000px width requires horizontal scrolling
  • Such a design violates the basic principles of web design

So, if the plugin limits this page, it's the right decision!
